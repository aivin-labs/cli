# Changelog

## 1.0.0

Initial release — split out of `@aivin-labs/sdk` (which shipped the `aivin` binary through
version 1.0.5) into its own package. Behavior is unchanged from that point; only the packaging
did. `@aivin-labs/sdk` from `1.1.0` onward is runtime-only and no longer provides the `aivin`
command — install this package instead.
